# Detailed Study Plan

## Day 1: Basic SELECT Statements
### Learning Goals
- Master the use of the SELECT statement to retrieve data from a database.
- Differentiate between selecting all columns and specific columns.

### Exercises
- **Exercise 1**: Write a query to select all columns from the `employees` table.
- **Exercise 2**: Write a query to select only the `name` and `position` columns from the `employees` table.

### Query File References
- [day1/queries.sql](../day1/queries.sql)

## Day 2: INNER JOIN
### Learning Goals
- Understand how to combine rows from two or more tables based on a related column.
- Practice writing INNER JOIN queries to retrieve combined data.

### Exercises
- **Exercise 1**: Write a query to join the `employees` table with the `departments` table to display the employee name and department name.
